# 💥 坦克对战游戏 (Tank Battle)

## 📖 项目简介
这是一个基于虚幻引擎 (Unreal Engine) 开发的 3D 坦克对战游戏。
项目旨在提供流畅的射击体验与对抗机制，支持本地多人对战、PVE 挑战以及完善的战局结算系统。

**核心特性：**
- 🎮 **多人分屏对战**：支持本地玩家同屏竞技。
- 🤖 **AI 对手系统**：具有基础寻路与索敌逻辑的 AI 坦克。
- 📊 **完整的结算机制**：支持阵营得分累计、KDA 动态计算与战绩排名。

## 🏃 快速开始
如果你是初次拉取本项目，请按以下步骤运行：

1. 确保已安装对应版本的 **Unreal Engine 5.7** 及 **Visual Studio**。
2. 在项目根目录，右键点击 `.uproject` 文件，选择 **`Generate Visual Studio project files`**。
3. 双击打开生成的 `.sln` 文件。
4. 在 Visual Studio 中，将编译配置设置为 `Development Editor` 并按 `F5` 编译运行，即可启动虚幻编辑器。
